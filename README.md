# Mercy & Isaac Wedding Invitation

A mobile-first React/Vite wedding invitation website.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build for production

```bash
npm run build
```

The production files will be in `dist/`.

## Customize

Edit `src/main.jsx` to change:
- Couple names
- Wedding date/time
- Venue addresses
- Bible verse
- Google Maps links
- Story/family content

Replace `public/invitation-reference.jpg` with the couple's preferred image(s).

## Deploy

This can be deployed to Netlify, Vercel, Cloudflare Pages, or another static host.
